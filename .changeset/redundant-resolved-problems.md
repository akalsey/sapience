Stop thinking passes from re-surfacing problems that later evidence already resolved. The pass prompt now instructs the model to read recent activity and memory as one whole body of evidence across time and report the most recent state of a situation, so a point-in-time issue (e.g. "unable to access Google Sheets") that was subsequently fixed is no longer flagged as a live observation.
